# 雪线 ALPINE · 滑雪挑战

Recovered deployment files from the Vercel project `ski-demo-vercel-deploy` (team `csm16`).

- Live site: https://ski-demo-vercel-deploy.vercel.app/
- Deployment: 3WG743NUbcPafza28Vfcz2sLgm1N
- Recovered: 2026-11-02

## Files

- `index.html`: game page, styles, and controls
- `ski-bundle.js`: bundled game and rendering code
- `guard.js`: graphics fallback handling
- `vercel.json`: original deployment configuration, transcribed from Vercel Source

The project was uploaded through Vercel Drop and had no connected Git repository. These are the deployed files; original unbundled modules, build configuration, and prior Git history were not present in the deployment. No source map is included.

## Run locally

Run `python -m http.server 8000` in this directory and open http://localhost:8000/ with graphics acceleration enabled.

For Vercel, import this repository as a static site with no build command and the repository root as the output directory.
